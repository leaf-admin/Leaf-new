# App Review Notes - Account Deletion

Use this in the App Review Information notes before submitting iOS build 23 for review.

```text
Account deletion is available directly from the Profile screen.

Path for App Review:
1. Sign in with the demo account.
2. Open the main menu from the map screen.
3. Tap "Perfil" to open the passenger or driver profile.
4. In the "Conta" section, tap "Excluir conta".
5. The app shows a native confirmation dialog. Tap "Excluir Conta" to permanently delete the account and return to the sign-in screen.

The same account management area also remains available from Menu > Privacidade > Gerenciar conta, where users can request data export or start account deletion.
```
