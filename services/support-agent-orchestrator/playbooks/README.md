# Playbooks

O orquestrador usa por padrao o playbook versionado em:

`../../docs/support/LEAF_SUPPORT_PLAYBOOK.md`

Para conectar triagem e execucao assistida ao orquestrador, use especialmente a secao:

`17. Orquestrador de Agents`

Este diretorio existe para playbooks especificos do servico, fixtures de QA e futuras bases aprovadas. O agent nao deve consultar internet livre; novas fontes precisam ser adicionadas aqui ou em uma base vetorial controlada.
