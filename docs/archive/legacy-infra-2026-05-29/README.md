# Arquivo Historico De Infra Legada

Este diretorio guarda relatorios, checklists e evidencias criados antes da consolidacao atual em Contabo + dominios `leaf.app.br`.

Eles podem ser usados para contexto historico, mas nao devem ser usados como runbook operacional. Para operacao atual, consulte os docs ativos fora de `docs/archive/`.

Motivos do arquivamento:

- referencias a IP direto, `sslip.io` e provedores antigos;
- evidencias de rodadas antigas de QA, readiness e canary;
- checklists de loja e runtime que ja foram substituidos por docs canonicos atuais.
