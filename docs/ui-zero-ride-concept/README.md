# Zero Ride UI Concept (HTML/CSS)

Conceito de 6 telas mobile inspirado em apps de ride sharing com linguagem visual futurista dark.

## Arquivos

- `index.html`: board com as 6 telas
- `styles.css`: design tokens visuais, mapa em camadas e ajustes de espaçamento
- `app.js`: interação de rating e rotação de dados mock em tempo real (ETA/velocidade/atraso)

## Como abrir localmente

No diretório raiz do projeto:

```bash
open /Users/izaakdias/Documents/Leaf-new/docs/ui-zero-ride-concept/index.html
```

## Como levar para Figma (opcional)

1. Abra o arquivo `index.html` no navegador.
2. Use um plugin de importação HTML para Figma (ex.: html.to.design).
3. Importe a página e converta em layers editáveis.
4. Ajuste tipografia, espaçamento e componentes conforme seu design system.

## Fluxo incluído

1. Onboarding
2. Home + mapa
3. Seleção de corrida
4. Tracking de motorista
5. Corrida em andamento
6. Pagamento + avaliação
